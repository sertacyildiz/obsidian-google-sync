# Contributing

This project is **maintained solely by the owner**. To keep it focused and
secure, **contributions and collaborator access are by invitation only.**

- **Please do not open unsolicited pull requests.** PRs are not merged unless
  arranged with the owner in advance; the owner is the only person with write
  access and the only one who merges.
- **No one is added as a collaborator** without an explicit invitation from the
  owner.
- Have a bug or an idea? **Open an issue to discuss first** — that's the way to
  contribute.
- Security issues: please follow [SECURITY.md](SECURITY.md) and report them
  **privately**.

Thanks for understanding.
